export function exportCsv(datasetId) {
    const url = `/api/export/csv?dataset_id=${encodeURIComponent(datasetId)}`;
    const a = document.createElement('a');
    a.href = url; a.download = '';
    document.body.appendChild(a); a.click(); document.body.removeChild(a);
}

    - If source_path starts with "cellxgene-census:", the fetch block uses

      otherwise it uses sc.read_h5ad(source_path).

      and no analysis code, WITHOUT raising.
    - Endpoint returns 200 text/x-python for an analyzed dataset, 401 without password,
      404 for unknown dataset, 422 for malformed dataset_id. (Verified by
      tests/test_webapp_script_export.py.)
  </behavior>
  <action>
    Create webapp/backend/export_script.py with a single pure function
    `generate_analysis_script(adata, source_path: str | None, dataset_id: str) -> str`.
    Use f-strings (no template engine — RESEARCH Don't-Hand-Roll). Structure per
    RESEARCH Pattern 6:
      1. Comment header: dataset_id + generated timestamp (datetime.now(timezone.utc)).
      2. Imports: always `import scanpy as sc`; add `import cellxgene_census` only for
         census source.
      3. Fetch block:
         - census: parse source_path with `source_path.split(":", 3)` ->
           [_, census_version, organism, obs_value_filter]; emit
           `with cellxgene_census.open_soma(census_version="{census_version}") as census:`
           + `adata = cellxgene_census.get_anndata(census=census, organism="{organism}",
           obs_value_filter="{obs_value_filter}")`.
         - file: `adata = sc.read_h5ad("{source_path}")`.
      4. QC block: read `qc_cfg = (adata.uns.get('qc') or {}).get('config', {})`; emit
         `sc.pp.filter_cells(adata, min_genes={min_genes_per_cell})`,
         `sc.pp.filter_genes(adata, min_cells={min_cells_per_gene})`, and the mito block
         guarded on max_pct_mt is not None (compute pct_counts_mt then subset). Also emit
         the scrublet block when doublet_action indicates it (RESEARCH Pitfall 6:
         read doublet_action, emit sc.pp.scrublet + filter if "filter").
      5. Analysis block: `an = adata.uns.get('analysis')`; if None, emit the
         "# No analysis was run in this session — add your analysis steps here." comment.
         If present, emit normalize_total(target_sum), log1p, highly_variable_genes(n_top_genes),
         pca(n_comps=n_pcs, random_state), neighbors(n_neighbors, random_state),
         leiden(resolution, flavor="igraph", n_iterations=2, directed=False, random_state),
         umap(random_state) — all values from the analysis dict (RESEARCH Pattern 6 template).
    The generated script must NOT import any bioclaw modules (RESEARCH anti-pattern).

    In webapp/backend/main.py add
    `@app.get("/api/export/script", dependencies=[Depends(require_password)])`
    `async def export_script(dataset_id: str) -> StreamingResponse:` mirroring export_csv:
    parse "name@version", load from DatasetStore(root=agent_tools.STORE_ROOT) (KeyError ->
    404, malformed -> 422), fetch the store record's source_path via
    `store.list(name)` (match the loaded version, else latest), call
    `generate_analysis_script(adata, source_path, dataset_id)`, and return a
    StreamingResponse(io.BytesIO(script.encode()), media_type="text/x-python",
    headers={"Content-Disposition": f'attachment; filename="{safe_name}_analysis.py"'}).
    Import generate_analysis_script from webapp.backend.export_script.
  </action>
