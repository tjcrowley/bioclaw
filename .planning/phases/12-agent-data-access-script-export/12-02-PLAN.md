<objective>
Implement DATA-01: an agent tool that fetches a real public single-cell dataset from
cellxgene-census by organism + obs_value_filter, ingests it in memory through the
Wave 0 helper, and returns a dataset handle — no file upload. The blocking TileDB-SOMA
census I/O runs in asyncio.to_thread() so it never stalls the event loop.

Purpose: gives the agent the ability to pull real data on demand, replacing the
upload-only path for the first time.
Output: fetch_census_dataset() orchestration in ingest/census.py, the
fetch_census_dataset_tool @tool handler, and its registration in bioclaw_server.
</objective>
