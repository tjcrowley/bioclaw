<objective>
Build the 10x ingest loader (INGEST-01) and the raw-counts immutability contract (INGEST-02): a format-detecting loader that turns a 10x `.mtx` directory or `.h5` file into a valid AnnData, and a contract module that freezes a copy of the raw counts into `adata.layers['counts']` at load time so no later pipeline step (in this phase or any future one) can silently corrupt it.

Purpose: These are the two load-bearing correctness guarantees for the entire project — every later phase trusts that `layers['counts']` is real, uncorrupted raw data. Per `01-RESEARCH.md` Pitfall 1/2, AnnData has no built-in immutability, so this must be actively enforced (write-protect + checksum), not just documented.
Output: `ingest/loaders.py`, `ingest/contract.py`, passing tests for both.
</objective>

```python
# ingest/loaders.py
def load(path: str | Path) -> AnnData:
    """Format-detects a directory (MEX/.mtx) vs a .h5 file. Raises ValueError
    on any other input. Always returns var_names deduplicated (read_10x_mtx's
    make_unique=True default does this; read_10x_h5 does NOT, so loaders.py
    must call adata.var_names_make_unique() explicitly after that path)."""

# ingest/contract.py
def set_counts_layer(adata: AnnData) -> None:
    """In-place. adata.layers['counts'] = adata.X.copy(); freezes the
    underlying buffer (writeable=False); stores sha256 checksum in
    adata.uns['counts_checksum']. Must be called immediately after load(),
    before anything else touches .X."""

def verify_counts_integrity(adata: AnnData) -> bool:
    """Recomputes the checksum of adata.layers['counts'] and compares to
    adata.uns['counts_checksum']. Returns False if they diverge."""
```
