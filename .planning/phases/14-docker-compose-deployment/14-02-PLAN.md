<task type="auto">
  <name>Task 2: Dockerfile main-builder + runtime stage, docker/entrypoint.sh</name>
  <files>Dockerfile, docker/entrypoint.sh</files>
  <action>
    Create `docker/entrypoint.sh` first:
    ```bash
    #!/bin/sh
    # Fixed single-worker Uvicorn invocation. Deliberately ignores any arguments
    # passed via `docker run`/compose `command:` overrides -- the in-memory
    # streaming queue registry (webapp/backend/streaming.py) is single-process
    # only; --workers must never change. See webapp/README.md's "Hard
    # constraint: single process only" and 14-RESEARCH.md's Anti-Patterns.
    set -e
    exec /app/.venv/bin/uvicorn webapp.backend.main:app --host 0.0.0.0 --port 8000 --workers 1
    ```
    Make it executable: `chmod +x docker/entrypoint.sh`.

    Create `Dockerfile` at the repo root:
    ```dockerfile
    # syntax=docker/dockerfile:1

    # --- Stage: main venv (root project, Python 3.13) ---
    FROM python:3.13-slim AS main-builder
    COPY --from=ghcr.io/astral-sh/uv:latest /uv /uvx /bin/
    WORKDIR /app
    COPY pyproject.toml uv.lock ./
    RUN uv sync --frozen --extra web --no-install-project
    COPY . .
    RUN uv sync --frozen --extra web

    # --- Final runtime stage ---
    FROM python:3.13-slim AS runtime
    WORKDIR /app
    COPY --from=main-builder /app /app
    RUN chmod +x /app/docker/entrypoint.sh
    ENV BIOCLAW_STORE_ROOT=/app/state/data
    ENV BIOCLAW_MEMORY_DB=/app/state/agent/memory.sqlite
    ENV BIOCLAW_LOG_PATH=/app/state/tool_calls.jsonl
    EXPOSE 8000
    ENTRYPOINT ["/app/docker/entrypoint.sh"]
    ```
    Note: Plan 14-03 will insert two additional builder stages
    (`scgpt-builder`, `geneformer-builder`, plus a `reference-builder` stage
    built `FROM main-builder`) between the `main-builder` stage and this
    `runtime` stage, and add matching `COPY --from=...` lines into `runtime`.
    This plan's `runtime` stage intentionally has no FM-worker `COPY` lines
    yet — `annotation/fm_client.py`/`perturbation/geneformer_client.py` calls
    will fail at runtime until Plan 14-03 lands, which is expected and out of
    scope for this plan's verification.
  </action>
  <verify>
    <automated>docker build -t bioclaw:test-main . && docker run --rm bioclaw:test-main ls /app/.venv/bin/uvicorn</automated>
  </verify>
  <done>`docker build -t bioclaw:test-main .` succeeds; the image contains `/app/.venv/bin/uvicorn` and a chmod+x'd `/app/docker/entrypoint.sh`.</done>
</task>
