  <name>Task 1: Automated no-OpenClaw-dependency regression test</name>
  <files>tests/test_webapp_packaging.py</files>
  <action>
    Create a new test module `tests/test_webapp_packaging.py` with a static-analysis test
    that walks `webapp/` and asserts no file contains a reference to the sibling OpenClaw
    project. This replaces the one-time manual `grep` recorded in
    `.planning/phases/09-frontend-chat-ui/09-VERIFICATION.md` with a durable, always-run
    check (10-RESEARCH.md Pitfall 1 / Don't Hand-Roll table).

    Implementation:
    ```python
    import pathlib

    WEBAPP_DIR = pathlib.Path(__file__).resolve().parent.parent / "webapp"


    def test_webapp_has_no_openclaw_dependency():
        """PKG-01: webapp/ must have zero code/runtime dependency on the sibling
        OpenClaw project (the actual OpenClaw agent product at
        ~/.openclaw/workspace) -- NOT on bioclaw's own agent/qa/ingest packages,
        which webapp is intentionally supposed to import directly.
        """
        offending = []
        for path in WEBAPP_DIR.rglob("*"):
            if not path.is_file():
                continue
            if path.suffix not in (".py", ".js", ".html", ".css"):
                continue
            if "__pycache__" in path.parts:
                continue
            text = path.read_text(errors="ignore").lower()
            if "openclaw" in text:
                offending.append(str(path))
        assert not offending, f"Found OpenClaw references in: {offending}"
    ```

    Do not weaken this to only check `.py` files -- the frontend JS/HTML/CSS in
    `webapp/frontend/` must also stay clean, since a stray comment or copied UI snippet
    could reintroduce a reference there just as easily as in Python.
  </action>
  <verify>
    <automated>uv run --extra web pytest tests/test_webapp_packaging.py::test_webapp_has_no_openclaw_dependency -x -q</automated>
  </verify>
  <done>New test passes (no offending files found) and would fail if any file under webapp/ contained the string "openclaw".</done>
