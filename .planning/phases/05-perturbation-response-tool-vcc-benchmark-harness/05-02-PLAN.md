```python
class LinearAdditivePerturbationModel:
    def __init__(self, alpha: float = 1.0): ...
    def fit(self, gene_names: list[str], control_mean: np.ndarray, pert_means: dict[str, np.ndarray]) -> None: ...
    def predict(self, control_mean: np.ndarray, target_gene: str) -> np.ndarray: ...

def fit_from_adata(
    adata: AnnData,
    target_gene_col: str = "target_gene",
    control_token: str = "non-targeting",
    alpha: float = 1.0,
) -> tuple[LinearAdditivePerturbationModel, np.ndarray]:
    """Returns (fitted_model, control_mean_vector)."""
```
`gene_names` is stored on the model instance so `predict()` can resolve `target_gene`'s own control-population expression value for the ridge fallback feature (05-RESEARCH.md Pattern 1 / Open Question 3's "simplest defensible choice"). `fit_from_adata` returns `control_mean` alongside the model because Plan 05-03's `pipeline.predict()` needs that same vector to call `model.predict(control_mean, target_gene)`.

    - `fit(gene_names, control_mean, pert_means)`: stores `gene_names` (list, defines index order) and `control_mean` on the instance; computes `self._known_shifts = {g: v - control_mean for g, v in pert_means.items()}`. Fits `self._fallback_model = sklearn.linear_model.Ridge(alpha=self.alpha)` where the feature `X` is each known gene's own control-population expression value (`control_mean[gene_names.index(g)]`, reshaped to a single-feature column) and the target `Y` is that gene's shift vector (`self._known_shifts[g]`) -- per 05-RESEARCH.md Pattern 1's sketch, refined to use an explicit `gene_names` list rather than a private `_gene_index` helper (this plan's version needs to be usable standalone by `predict()`, not embedded only inside `fit`).

Else if `target_gene in self.gene_names` (seen as a gene but not as a fit-time perturbation), look up its control-expression feature value and call `self._fallback_model.predict(...)`, returning `control_mean + predicted_shift`. Else raise `KeyError(f"{target_gene!r} not found in gene_names")`.
    - Raise a clear `RuntimeError` from `predict()` if called before `fit()` (unset `self._fallback_model`).
