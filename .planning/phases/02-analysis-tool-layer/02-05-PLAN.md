<objective>
Build `analysis/pipeline.py`: the single coarse-grained entrypoint (mirroring `ingest/pipeline.py::ingest_10x`) that a future agent tool wrapper (Phase 3) calls -- loads a named/versioned dataset from `DatasetStore`, runs `preprocess` -> `cluster` -> optional `differential_expression`, verifies the raw-counts contract survived (both before and after), saves the result as a new store version, and returns a bounded summary.
