<objective>
Compose Plan 04-02's `baseline_annotate()` and Plan 04-03's `call_scgpt_annotate()` into `annotation/pipeline.py::annotate()` -- the single bounded-`AnnotationSummary`-returning entrypoint -- and wire it into the agent's tool-calling surface as `annotate_cell_type_tool`, mirroring `agent/tools.py`'s existing `ingest_10x_tool`/`analyze_dataset_tool` shape exactly.

Purpose: This is where ANNOT-01 (the agent can invoke a bio-FM-backed annotation tool call) and ANNOT-03 (bounded, never-a-bare-label output) actually close. Per 04-RESEARCH.md's Anti-Patterns section, the `decoupler` baseline call must run unconditionally -- "every FM-backed annotation call is accompanied by" the baseline is ANNOT-02's literal wording -- and per the same section's "log the error result the same as a success result" precedent (already established in `agent/tools.py`'s own docstring), a failed FM call must not prevent the baseline result from being returned. Because a real scGPT checkpoint has not been acquired yet (deferred to Plan 04-05), this plan's tests mock `fm_client.call_scgpt_annotate` so the fast tier is fully deterministic and checkpoint-independent -- exactly matching the Validation Architecture's "ANNOT-01 (tool wiring, mocked FM)" test row.

Design decision (recorded here since 04-RESEARCH.md's Open Question left it open): `annotate()` does NOT persist a new store version. Annotation adds no new data worth persisting beyond the returned summary -- it operates read-only on an already-analyzed (clustered) dataset. `annotate()`'s returned `dataset_id` is the SAME id it loaded (mirroring `analyze()`'s own `loaded_id = f"{name}@{version if version is not None else '(latest)'}"` display convention, computed before any save), so `agent/session.py`'s existing `record_dataset_reference()` hook (Phase 3, unchanged) still records it into session memory with no new wiring needed -- that hook already parses any `dataset_id` key generically from a tool's JSON text output.

    ```python
    from __future__ import annotations

    from dataclasses import asdict
    from pathlib import Path
    import tempfile

    from ingest.store import DatasetStore

    from annotation.baseline import baseline_annotate
    from annotation.fm_client import call_scgpt_annotate
    from annotation.summary import AnnotationSummary

    def annotate(
        name: str,
        version: int | None = None,
        store_root: str | Path = "data",
        reference_index_path: str | Path = "bio_fm_worker/reference/reference.h5ad",
        worker_python: str | Path = "bio_fm_worker/.venv/bin/python",
        script_path: str | Path = "bio_fm_worker/run_scgpt_embed.py",
        model_dir: str | Path = "bio_fm_worker/checkpoints/scGPT_human",
    ) -> tuple[str, dict]:
        store = DatasetStore(root=store_root)
        adata = store.load(name, version)
        dataset_id = f"{name}@{version if version is not None else '(latest)'}"

        baseline_calls = baseline_annotate(adata, groupby="leiden")

        try:
            with tempfile.NamedTemporaryFile(suffix=".h5ad", delete=False) as tmp:
                adata.write_h5ad(tmp.name)
                fm_calls = call_scgpt_annotate(
                    tmp.name, reference_index_path,
                    worker_python=worker_python, script_path=script_path,
                    model_dir=model_dir,
                )
        except Exception:
            fm_calls = []

        summary = AnnotationSummary(
            dataset_id=dataset_id,
            fm_calls=fm_calls,
            baseline_calls=baseline_calls,
            fm_model="scGPT (whole-human checkpoint, zero-shot reference mapping)",
            baseline_method="decoupler ORA vs PanglaoDB (human, canonical markers)",
        )
        return dataset_id, asdict(summary)
    ```
